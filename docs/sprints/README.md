# Sprints

Una carpeta por consigna de la cátedra: `sprint-N.md`, con el enunciado tal cual lo
entregaron los profesores, sin reinterpretar. Si hace falta interpretar algo, va abajo del
enunciado en una sección aparte y marcada como tal.

Por qué vive en el repo y no en un Drive: la consigna define el alcance, y tener el
enunciado versionado al lado del código deja registro de qué se pedía cuando se escribió
cada cosa. Además queda como contexto disponible para las herramientas.
